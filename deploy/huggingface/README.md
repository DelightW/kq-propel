# KQ-Propel

Agentic retrieval-augmented support assistant for Kenya Airways passenger questions, built as a
Strathmore University research project. Source: https://github.com/DelightW/kq-propel

**Open the app at its direct address**, `https://<owner>-<space-name>.hf.space`, not inside this Hugging
Face page: the page shows the app in a frame, and browsers block the sign-in and chat session cookies there.

This is a prototype. Payments run in Safaricom's sandbox and only reach registered test numbers; booking
lookups use demonstration bookings; two policy documents are disclosed as synthetic.
